Drive mode & heading

Driver drive mode is selected on the robot dashboard. Arcade uses left stick to drive and right stick X to turn. Holonomic uses left stick Y and right stick X to translate, with triggers controlling rotation. Tank uses both stick Y axes.

Driver D-pad locks heading: up/down select 0°/180° and left/right select ±90°; target angles swap by alliance. Operator D-pad up/down extends/retracts the climber; left/right controls feeder and transfers. Hold LB to see alternate actions above.

Live highlighting reads browser Gamepad input only. It does not connect to or control the robot. Browser gamepad indexes may differ from robot USB ports; select the correct device in each card.
